# Frontend

React + TypeScript + Vite frontend of google-tasks-enhancer. The production build in `dist/` is served by the FastAPI backend.

## Commands

```bash
npm ci          # install the exact dependencies from package-lock.json
npm run dev     # Vite dev server with hot reload
npm run build   # type-check with TypeScript 7 (tsc -b), then build into dist/
npm run lint    # lint with Oxlint
npm test        # unit tests with Vitest
```

## UI text

The UI texts live in typed dictionaries in `src/i18n/` (`en.ts` and `it.ts`, plus the provider and the helpers). English is the default; a text missing from one dictionary fails `npm run build`. See the UI languages section of the root `README.md`.

## Type-checking and linting

- TypeScript 7 type-checks the code (`tsc -b` in `npm run build`).
- Oxlint lints it with the rules in `.oxlintrc.json`. That file was generated by `@oxlint/migrate` from the former ESLint configuration (`@eslint/js` recommended, typescript-eslint recommended, `react-hooks` and `react-refresh` rules).
- The last `overrides` entry of `.oxlintrc.json`, for `**/*.{ts,tsx}`, mirrors typescript-eslint's `eslint-recommended` block and is added by hand because `@oxlint/migrate` drops it.

## Why Oxlint instead of ESLint

typescript-eslint needs the JavaScript compiler API of the `typescript` package, which TypeScript 7 no longer ships, so it cannot run with TypeScript 7. Oxlint does not depend on the `typescript` package, which lets the frontend move to TypeScript 7.
